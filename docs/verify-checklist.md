# 鲸鲸阅读器手动验收清单

本清单覆盖无法由 `scripts/verify.ps1` 自动断言的交互项。自动项（构建、单测、首屏 `elapsedMs`、端到端首屏、内存峰值、PDF、双开单实例、分发包完整性、数据隔离、产物体积）以 `out/verify-report.md` 为准；本清单只记录需要人眼/手动的结果。执行记录写到 [verify-record.md](verify-record.md)；逐条证据对照见 [acceptance-traceability.md](acceptance-traceability.md)。

## 前置

- [ ] 已完成 `pwsh -NoProfile -File scripts/build.ps1`，`out\JingjingReader.exe` 存在。
- [ ] （可选）已完成 `pwsh -NoProfile -File scripts/build.ps1 -SelfContained`，`out-selfcontained\` 内含 exe、`install.ps1`、`uninstall.ps1`、`README.md`；在未安装 .NET 10 运行时的机器上能启动。
- [ ] 已准备测试素材：`samples/hello.md`、`samples/full-syntax.md`、`samples/huge-50k-lines.md`，以及一个含图片/表格/代码块/脚注的深色主题文档。
- [ ] 测试机为 Windows 10/11 x64，已安装 WebView2 Runtime 与 .NET 10 Desktop Runtime（或用 `-SelfContained` 产物）。
- [ ] 若要测试 `.md` 关联，先记录注册表现状：
      `reg query "HKCU\Software\Classes\.md" /s > before.txt` 与 `reg query "HKCU\Software\Classes\JingjingReader.md" /s > before-progid.txt`。
- [ ] 记录环境：OS 版本、`.NET` / WebView2 版本（程序「关于」面板或 `JingjingReader.exe --selftest`）、当前 commit、日期。

## 1. 拖放

- [ ] 拖入一个 `.md` 文件 → 窗口打开该文档，标题为「文件名 — 鲸鲸阅读器」。
- [ ] 拖入一个文件夹 → 左侧切换到文件树，根节点显示文件夹名；工具条出现「大纲」返回按钮。
- [ ] 拖入 `.txt` / `.png` / 其它非 Markdown 文件 → 顶部提示「不支持的文件类型」，当前文档保持不变。
- [ ] 拖入多个文件 → 只打开第一个（与产品口径一致）。
- [ ] 拖入时鼠标显示「复制」光标；拖到窗口外释放不产生动作。

## 2. 打开对话框（`Ctrl+O` / `Ctrl+Shift+O`）

- [ ] `Ctrl+O` 弹出原生打开文件对话框，过滤器包含 `.md/.markdown/.mdown/.txt`；选中文件后打开。
- [ ] 在对话框中取消 → 无错误提示、当前文档不变。
- [ ] `Ctrl+Shift+O` 弹出文件夹选择对话框；选择后进入文件树浏览。
- [ ] 通过工具条「打开文件」「打开文件夹」按钮执行同样操作，结果一致。

## 3. 文件树

- [ ] 选择一个含多级子目录的文件夹：根列表按目录在前/文件在后（按名称）显示。
- [ ] 点击目录 → 展开并加载子项；再次点击 → 折叠；折叠后再次展开不重复请求（首次失败可重试）。
- [ ] 点击文件 → 打开该文件；当前文件在树中高亮；滚动阅读时高亮不丢失。
- [ ] 打开空文件夹 → 显示空状态提示，不报错、不空白崩溃。
- [ ] 打开不可读目录（权限拒绝）→ 顶部 toast 提示失败；程序仍可继续操作，可重试。
- [ ] 打开文件夹后点击工具条「大纲」→ 切回大纲；点击「浏览根」按钮 → 切回文件树。
- [ ] 当前文档不在浏览根内时，树高亮不误标其它文件。

## 4. 主题（浅色 / 深色 / 跟随系统）

- [ ] 点击主题按钮在「浅色 → 深色 → 跟随系统」间循环，按钮文案与界面同步。
- [ ] 深色主题下正文、代码块、表格、引用块、大纲、工具条均为深色可读配色；切换时无明显白闪。
- [ ] 选择「跟随系统」后，在 Windows 设置中切换系统应用主题 → 程序界面随之切换。
- [ ] 重启程序后主题保持上次选择。

## 5. 排版

- [ ] `Ctrl+=` / `Ctrl+-` 调整字号，范围 14–24；`Ctrl+0` 回到 16。
- [ ] `Ctrl+,` 打开排版面板：行距 1.4–2.0、行宽 640/780/960/全宽、中文字体（系统默认/微软雅黑/思源黑体）与代码字体可切换。
- [ ] 调整后正文立即生效；重启程序后设置保持。
- [ ] 行宽「全宽」在 1920 宽屏上不出现横向滚动；窄窗口（最小 640×480）下正文不溢出。
- [ ] 字号 24 时大纲与工具条不重叠；代码块超长行横向滚动而不撑破布局。

## 6. 大纲（TOC）

- [ ] 打开 `samples/full-syntax.md`：侧栏列出 38 个标题，层级缩进正确。
- [ ] 点击任一大纲项 → 平滑滚动到对应标题，标题不被悬浮工具条遮挡。
- [ ] 手动滚动正文 → 当前标题高亮随阅读位置变化。
- [ ] 打开无标题文档 → 侧栏显示「此文档没有标题」，无脚本错误。
- [ ] 长文档（5 万行样例，500 个标题）大纲可用，滚动联动不卡顿；点击靠后条目能定位。
- [ ] 拖动大纲右缘调整宽度（180–360 px），折叠后重新展开宽度保持。

## 7. 最近文件、位置记忆与 F5

- [ ] 连续打开 3 个文档 → 空白启动页与工具条「最近」菜单按最近顺序列出。
- [ ] 关闭程序再启动 → 空白页显示最近文件；点击能打开。
- [ ] 滚动到文档中部后关闭，重新打开同一文件 → 回到上次位置（顶部有提示）。
- [ ] `F5` 重载当前文件 → 内容刷新、滚动位置保持、无重复内容。
- [ ] `Alt+←` / `Alt+→` 按最近顺序切换上一份/下一份；到边界时无错误。
- [ ] `Ctrl+Shift+C` 在资源管理器中选中当前文件；无当前文档时不报错。

## 8. 深色主题导出 PDF（`Ctrl+E`）

- [ ] 深色主题下打开含图片、表格、代码块、脚注的文档，`Ctrl+E` 导出。
- [ ] 导出期间显示进度/禁用状态；完成后文件存在且能被 Edge/PDF 阅读器打开。
- [ ] 导出的 PDF 为**浅色底、深色文字**，与屏幕深色主题无关；代码/表格/图片清晰可读。
- [ ] 图片不被截断；表格行、代码块尽量不跨页断裂（CSS `break-inside: avoid`）。
- [ ] `samples/huge-50k-lines.md` 导出：页数 > 100、体积 > 1 MB；导出期间界面有明确反馈，完成后恢复可交互。
- [ ] 导出对话框取消 → 不产生半成品文件、界面恢复；非法/不可写路径 → 给出错误提示并复位导出状态。
- [ ] 无文档时 `Ctrl+E` → 提示「请先打开文档」，不发请求。

## 9. 关于面板与默认应用

- [ ] 工具条「关于」打开模态面板：显示产品名、版本、.NET、WebView2、OS、数据目录、`.md` 关联状态。
- [ ] 面板中「打开默认应用设置」能跳到 Windows 默认应用页面。
- [ ] 「复制诊断信息」复制到剪贴板的内容完整、中文不乱码。
- [ ] 关闭面板不影响主窗口阅读；重复打开不叠加多个面板。

## 10. `.md` 关联安装/卸载前后一致

- [ ] 记录安装前注册表（见前置），运行 `pwsh -NoProfile -File scripts/install.ps1`。
- [ ] `reg query "HKCU\Software\Classes\JingjingReader.md"` 存在；`.md` 的 OpenWithProgids 含 `JingjingReader.md`。
- [ ] 在「默认应用」中把 `.md` 设为鲸鲸阅读器，双击 `.md` 能打开。
- [ ] 运行 `pwsh -NoProfile -File scripts/uninstall.ps1`（无需确认，直接执行并按退出码返回结果）。
- [ ] 再次 `reg query` 对比：`.md` 与 `JingjingReader.md` 的关键键值恢复安装前状态（或本程序新增项被删除）。
- [ ] 备份文件缺失/损坏时执行卸载 → 明确提示且不破坏注册表（可先备份再手动改坏 `%APPDATA%\JingjingReader\assoc-backup.json` 测试）。
- [ ] 重复安装/卸载不报错、不产生重复键值。

## 11. 长路径（> 255 字符）

- [ ] 在深层目录（总路径 > 255 字符，可 `mkdir` 逐级创建）放一个 `.md`，双击/拖入/`Ctrl+O` 打开 → 正常渲染，标题与图片相对路径正确。
- [ ] 把该深层目录作为浏览根 → 文件树展开与打开正常。
- [ ] 长路径下导出 PDF → 成功；过长/非法路径 → 错误提示不崩溃。

## 12. 5 万行文档滚动与位置恢复

- [ ] 打开 `samples/huge-50k-lines.md`：首屏快速出现；滚动时逐块加载，不长时间白屏/卡死。
- [ ] 快速滚动到底部再回顶部 → 内容完整、顺序正确、无重复/丢失段落。
- [ ] 滚动到中部关闭再打开 → 恢复到上次位置附近（允许块级误差），并提示已恢复。
- [ ] 在大纲中点击靠后的标题 → 自动补齐未渲染块并定位。
- [ ] 阅读进度条随滚动更新；「回到顶部」按钮在滚离顶部后出现并可用。

## 13. 双开单实例

- [ ] 先启动程序并打开 A 文档，再双击/命令行启动第二个实例打开 B 文档 → 任务管理器只有一个 `JingjingReader.exe` 进程，原窗口切换到 B。
- [ ] 第二次启动只传空路径（例如再次双击快捷方式）→ 只激活已有窗口，不新开进程。
- [ ] 关闭主窗口 → 进程与 WebView2 子进程全部退出，任务管理器无残留。

## 14. 大文件模式提示

- [ ] 准备 > 20 MB 的 Markdown（可放大 `samples/huge-50k-lines.md` 或复制多份拼接）→ 打开后顶部提示「大文件模式：已关闭代码高亮」。
- [ ] 大文件模式下代码块无 token 高亮、复制按钮仍在；TOC 仍生成但不做滚动联动高亮。
- [ ] 从大文件切回普通文档 → 高亮与滚动联动恢复，无残留 `huge-mode` 样式。

## 15. 首屏（端到端）与版本/图标

- [ ] 双击已关联的 `.md`（或命令行启动）→ 记录从启动到正文可见的墙钟时间；热缓存下目标 ≤ 2.5 s（< 1.0 s 最佳）。这是端到端口径，与 `--verify-render` 的 `elapsedMs`（渲染器耗时）不同。
- [ ] 首次（冷）启动与重复（热）启动各测 3 次，记录中位数；明显 > 2.5 s 时记录 `%APPDATA%\JingjingReader\debug.log` 并提 issue。
- [ ] 资源管理器/任务管理器显示文件说明为「鲸鲸阅读器」、版本 0.1.0；窗口图标与 exe 图标为原创鲸鱼女仆娘（16/32/48/256 不糊，16 px 仍可辨鲸尾 + 圆头 + 头饰剪影）。
- [ ] 关于面板显示版本、.NET、WebView2、OS、数据目录、`.md` 关联状态；顶部显示原创鲸鱼女仆娘 mascot（256 PNG 透明背景，无破图）；版本号来自程序集。

## 16. 滚动帧预算（16 ms，descope 后手测）

> 16 ms 帧预算**没有自动化测量**，spec 已 descope 为手测；不得在验收记录里写成「已自动验证」。

- [ ] 打开 `samples/huge-50k-lines.md`，用滚轮连续滚动 10 秒、再用 `PageDown` 连续翻页 10 秒：观察是否掉帧/白屏/卡顿；记录主观结论（流畅/轻微掉帧/明显卡顿）。
- [ ] （可选）DevTools Performance 录制滚动 5 秒，查看 frame 间隔是否长时间 > 16 ms；记录 p95/最长帧。
- [ ] 点击大纲靠后条目（触发 renderAll）时观察是否有可感知卡顿；记录耗时观感。

## 17. 长 TOC（>300 项）行为

- [ ] 打开一个含 350+ 标题的文档：侧栏全量渲染、滚动与点击跳转正常（>300 虚拟滚动已 descope，全量渲染是有意行为）。
- [ ] 350 项时展开/折叠、拖动调宽仍可用；无明显卡顿（自动化测试锁定 < 500 ms，仅 jsdom 口径）。

## 18. 界面风格（阅读器风 / 鲸鱼娘）

> 自动测试覆盖 `data-ui-style`、工具条/Aa 面板双向同步、`saveSettings{uiStyle}` 与打印模式不重置风格（`tests/web/ui-style.test.js`）；`tests/web/ui-css.test.js` 另对打印回落、active 文本用色、两套风格文件与图标资产做文本级断言；以下为视觉、装饰与组合主题的手测项。
> 首屏：`src/Host/Resources/index.html` 预置 `data-ui-style="reader"`（无本地存储，前端首屏读不到 `settings.json`）；鲸鱼娘用户在空白启动时会先以阅读器风渲染、收到宿主 `settings` 后切换一次，属已知取舍。界面风格入口保留工具条按钮 + Aa 面板单选下拉。

- [ ] 工具条「主题」（鲸鱼图标）在阅读器风 ↔ 鲸鱼娘之间切换；Aa 面板「界面风格」下拉与按钮状态同步；重启程序后保持上次选择（`settings.json` 中 `uiStyle` 为 `reader`/`whale`）。
- [ ] 阅读器风 × 浅色 / 深色 / 跟随系统：h1 下边框、h2 弱化、引用浅底 + 左侧强调条、表格斑马纹/表头浅底/圆角、行内代码浅底圆角、代码块顶栏 + 复制按钮、TOC 当前项左侧强调条、最近文件 hover、toast 圆角均可辨且不刺眼；TOC 当前项与工具条 active 的文本在浅色 active 底上清晰可读（≥ 4.5:1，使用深一档强调色）。
- [ ] 鲸鱼娘 × 浅色 / 深色 / 跟随系统：背景为浅蓝→白（深色深蓝→近黑）渐变；低透明度气泡/浪花只作装饰，不遮挡正文、不拦截点击与文本选择（尝试框选跨气泡文字）；右下角水印不盖住文字。
- [ ] 鲸鱼娘空状态显示 220 px 鲸鱼女仆娘插画；工具栏左侧 28 px mascot、「主题」按钮图标、关于面板 96 px mascot 均显示正常、无破图/裁切。
- [ ] 鲸鱼娘一级无序列表显示鲸尾符号（含手写 HTML 的 `<ul>` 也会显示）；二级无序列表、有序列表、任务清单不受影响；读屏不把装饰符号读成文本。
- [ ] 两套风格下切换系统深浅色（或点击主题按钮）实时跟随、无白闪；开启 `prefers-reduced-motion` 时气泡不漂移、hover 不上浮。
- [ ] `Ctrl+E` 导出 PDF / 打印预览：两套风格都纯白背景，气泡、水印、mascot、工具栏、代码块顶栏、鲸尾列表符号与 h1 装饰下边框全部隐藏；正文链接为正文色 + 下划线（不是界面风格的蓝色无下划线）；正文、表格、代码可读（深色主题导出仍为浅色）。
- [ ] front matter 属性表在两套风格下都保持卡片内两列键值排版：无通用表格外框/表头底色/斑马纹，不出现双边框。
- [ ] 16 px 图标在资源管理器/任务栏可辨（鲸尾 + 圆头 + 头饰剪影）；48/256 细节版无糊边；`python scripts/gen-icon.py` 可重复生成相同资产。
